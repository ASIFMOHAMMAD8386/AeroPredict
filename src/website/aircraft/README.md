# AeroPredict aircraft source

The current website uses aeropredict-airliner-v2.glb, built in Blender 5.2 from create-aircraft-v2.py. Open aeropredict-airliner-v2.blend for the editable model and studio camera. The render is aircraft-v2-render.png.

V2 has 12 mesh objects and 32,739 polygon faces before GLB triangulation. It includes a smooth fuselage, cockpit panels, cabin windows and seals, swept airfoil wings, stabilizers, winglets, detailed intake fans, pylons, exhausts, door seams and navigation lights. The design and livery are original and illustrative, with no claim of aircraft engineering accuracy. No external model generator was used.

The original model is retained in the files without v2 in their names. Browser previews normalize the new model size; World view caps the aircraft at 24 pixels, with larger route and aircraft camera sizes for classroom visibility.
