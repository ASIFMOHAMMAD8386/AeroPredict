AEROPREDICT — ONE START OPTION

1. Extract this entire ZIP. Do not launch from inside the ZIP.
2. Install Node.js 24 or newer from https://nodejs.org/ if necessary.
3. Double-click START_HERE.cmd.

On the original presentation laptop, you can instead double-click the
desktop shortcut named Start AeroPredict. It points to this project.
The launcher opens a visible Brave, Edge or Chrome window directly.

It opens the local project first, then connects a temporary public Internet
link. The classroom screen shows the QR automatically after verification.
You can open the simulator immediately while public sharing connects.
If a temporary tunnel has expired, the launcher replaces it automatically.
Your classmates can scan it using mobile data or different Wi-Fi.
No paid domain or Cloudflare account is needed.

KEEP YOUR LAPTOP AWAKE AND ONLINE during the demonstration.
Use STOP_HERE.cmd when finished. Run START_HERE.cmd each new session;
an old printed QR may stop working after the public tunnel restarts.

Simulation works without an API key. Live mode needs your private key:
on a new copy, run SET_API_KEY.cmd once before using live flights.
The shared ZIP deliberately contains no secret key.

For GitHub upload steps, open GITHUB_UPLOAD.md.
For the presentation explanation, open PRESENTATION_NOTES.md.
All source code, Blender sources, exported models and training CSVs
are included. No npm install or paid hosting is needed to launch.
