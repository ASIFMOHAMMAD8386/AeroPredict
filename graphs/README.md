# Graphs

These four figures use the unchanged CSVs and measured results supplied in this project.
- `delay_distribution.png`: all 6,000 synthetic delay outcomes.
- `delay_by_weather.png`: mean synthetic delay for each weather category.
- `confusion_matrix.png`: the saved RF classifier's 900-row test confusion matrix.
- `model_comparison.png`: measured Baseline, Decision Tree and Random Forest F1 and MAE.

Regenerate from the project root with `python src/ml/make_graphs.py`.
These are educational synthetic-data results, not measured real-flight performance.
